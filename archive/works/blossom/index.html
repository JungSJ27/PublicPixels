Blossom

2015
Stencil technique, pattern design
472 × 236 mm

Blossom is a pattern design project created using the stencil technique. Inspired by fully blossomed globe amaranth, the work expresses the joy and vitality of spring through repetition and variation. Beginning with hand-carved paper stencils, the project explores how a single foundational pattern can give rise to diverse design forms.


Blossom은 스텐실 기법을 활용해 제작된 패턴 디자인 작업이다. 만개한 천일홍을 모티브로 삼아 봄의 기쁨과 생동감을 반복과 변주를 통해 표현했다. 스텐실을 위해 직접 조각한 종이의 형태에서 출발해, 하나의 기본 패턴이 다양한 형태의 디자인으로 파생되는 과정을 탐구했다.
