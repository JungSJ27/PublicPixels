Heart Orbit System

2023
Generative coding, 3D forms, real-time rendering
Variable dimensions

Heart Orbit System is a generative coding project that visualizes an orbital system using heart-shaped paths and simple geometric forms. Instead of realistic planetary motion, the work focuses on rhythm, movement, and visual balance, with planets and particles circulating along irregular, non-circular trajectories. The system is designed as a playful and aesthetic reinterpretation of orbits, emphasizing form and motion over scientific accuracy.

Heart Orbit System은 생성적 코딩을 활용해 하트 형태의 궤도와 기본적인 기하학 도형으로 구성된 가상의 궤도 시스템을 시각화한 작업이다. 실제 천체의 움직임을 재현하기보다는, 반복되는 리듬과 비정형적인 움직임, 그리고 형태가 만들어내는 시각적 균형에 집중한다. 이 작업은 궤도를 하나의 형식적 요소로 다루며, 움직임과 구조 자체를 즐길 수 있도록 설계되었다.
