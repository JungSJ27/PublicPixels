Project overview

인터뷰로 모은 목소리와 장면을 중심으로 다큐멘터리를 구성했고 인쇄물과 사진으로 맥락을 확장했다

What it is

NAKWON은 인터뷰를 기반으로 한 다큐멘터리다 기록을 중심에 두고 인쇄물과 사진이 주변을 감싼다

What you can see

  • 메인 다큐 영상
  • 인터뷰 포스터 시리즈
  • 책자 편집물
  • 현장 사진 아카이브
  • 부수적인 뮤직비디오

Tone

다큐는 관찰과 기록의 톤 뮤비는 우리끼리 웃기 위한 숨 쉴 구멍 화면 구성도 이 위계를 그대로 따른다

Documentary

메인 콘텐츠 인터뷰 장면과 관찰 샷으로 구성된 다큐멘터리

Main

아래 인용문과 함께 관람하면 내용의 축이 더 또렷해진다

Context

이 영역에는 다큐의 배경, 촬영 방식, 편집 방향 같은 설명을 추가하면 좋아 너무 길게 쓰기보다는 핵심만 5문장 안팎 추천

Posters, booklet, photo archive

인쇄물과 사진이 다큐의 맥락을 보강한다 아래 이미지는 파일만 교체하면 바로 사용 가능
